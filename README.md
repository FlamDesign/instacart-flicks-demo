# Flicks on Instacart Ads: concept demo

Clickable concept showing Flicks running inside Instacart ad formats: sponsored products, shoppable video, shoppable display, recipe ads and brand pages (General Mills, Burger King, Little Caesars). Switching inside a Flick updates the product, price, recipe and cart around it. Built by Flam for partner conversations. Not affiliated with or endorsed by Instacart, Burger King, Little Caesars or General Mills.

Open `index.html` in Chrome, or visit the GitHub Pages URL for this repo.
