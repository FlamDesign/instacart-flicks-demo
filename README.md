# Flicks on Instacart Ads: concept demo

Clickable concept showing Flicks running inside Instacart's three ad formats: sponsored products (General Mills), shoppable video (Burger King, Little Caesars) and recipe ads (General Mills). Switching inside a Flick updates the product, price, recipe and cart around it. Built by Flam for partner conversations. Not affiliated with or endorsed by Instacart, Burger King, Little Caesars or General Mills.

Open `index.html` in Chrome, or visit the GitHub Pages URL for this repo.
