# Flicks on Instacart Ads: concept demo

Clickable concept showing Flicks running inside Instacart ad formats: sponsored products (General Mills, Doritos), shoppable video (Ben & Jerry's), shoppable display (Doritos), recipe ads (General Mills) and brand pages. Products, sizes, prices and photos are from Safeway on Instacart; recipes are General Mills' own. Built by Flam for partner conversations. Not affiliated with or endorsed by Instacart, Safeway, General Mills, Doritos or Ben & Jerry's.

Open `index.html` in Chrome, or visit the GitHub Pages URL for this repo.
